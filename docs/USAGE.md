# 使用指南

从下载到看懂界面，一步步来。所有数据只留在你自己电脑上。

---

## 0. 下载即用

**不用装 Node.js，不用打开命令行。**

1. 到 [Releases](../../releases) 下载 `PLAYBILL-portable-v*-win64.zip`（约 34 MB）
2. 右键压缩包 → **全部解压**，得到一个 `PLAYBILL` 文件夹
3. 双击文件夹里的 **`启动程序.bat`**

等几秒，浏览器会自动打开程序地址。

> ⚠️ 别点「Code → Download ZIP」：那是源码，没有 `runtime\node.exe`，双击启动不了。
> 能直接用的只有 Releases 里的绿色版。

### 放到桌面

1. 把 `PLAYBILL` 文件夹拖到桌面
2. 右键 `启动程序.bat` → **发送到** → **桌面快捷方式**

> 快捷方式只认原路径：先把文件夹放到最终位置，再建快捷方式。

### 怎么关掉

关掉那个黑色窗口即可。

---

## 1. 准备工作

- **浏览器**：推荐 Edge（Cookie 捕获用它）
- **网络**：能打开 PlayStation 商店即可

---

## 2. 启动程序

双击 `启动程序.bat`，窗口里会出现类似输出：

```
PLAYBILL · 本地服务已启动（HTTP）
本机访问： http://localhost:8787
手机访问（同一 Wi-Fi）： http://10.0.0.8:8787
数据文件： ...\AppData\Roaming\PLAYBILL\data.json
```

浏览器打开窗口里显示的地址即可。Windows 也可以右键 `start.ps1` → 用 PowerShell 运行。

> 数据放在 `%APPDATA%\PLAYBILL`，不在程序文件夹里，换版本不会丢。

---

## 3. 登录账号

### 3.1 用调试模式打开浏览器

双击 **`启动浏览器.bat`**。它会用一份独立的浏览器配置打开商店首页——

这份配置第一次用是未登录状态，登录一次之后就会记住。

### 3.2 在窗口里登录

打开 <https://store.playstation.com/>，点右上角「登入」，完成账号密码（和两步验证）。

确认右上角已经显示你的头像。

### 3.3 抓取 Cookie

**不要关掉那个浏览器窗口**，回到程序文件夹，双击 **`抓取Cookie.bat`**。

看到三行 ✅ 就成功了：

```
✅ 已保存 N 个 Cookie（含风控 Cookie）
✅ 已自动完成登录（不用再手动粘贴 npsso）
✅ 交易接口验证通过，可以回程序点「同步交易」了
```

> 🕐 Cookie 约 30 天有效。到期后再做一次 3.1–3.3 即可。
> ⚠️ `npsso` 等同于账号密码：不要截图、不要发给任何人。

---

## 4. 同步游戏库

点右上角 **「同步游戏」**，几秒钟即可。

拉取：你拥有的游戏名称、平台、封面。

金额和图表**不依赖这一步**，它们来自下一步的交易记录。

---

## 5. 同步交易记录

点右上角 **「同步交易」**，程序会自动做两件事：

1. 拉取全部历史订单（几百笔），约 10–30 秒
2. 逐个查询商店现价、补封面，**首次 2–4 分钟**

提示条会显示「已用 N 秒」，不用以为卡住了。

完成后会显示类似：

```
交易 242 条 / 付费 70 笔 / 合计 HK$6,182.83 / 现价 181 个 / 封面 +87
```

> 「当前价值 / 累计省下」依赖现价覆盖率：低于 80% 时会显示「—」，避免给出不可信的数字。
> 数据多时再点一次「同步交易」或设置里的「更新商店现价与封面」，会继续补齐。

---

## 6. 看懂界面

### 6.1 总览

| 指标 | 含义 |
|---|---|
| **累计投入** | 实际花出去的钱（含折扣） |
| **当前价值** | 按商店现价重算，收藏值多少 |
| **累计省下 / 多花** | 现价 − 买入价，正数=省了 |
| **系列 / 合集** | 有消费的系列数量 |

四张图：月度消费、消费构成（捆绑包/本体/DLC/其他）、系列排行、当前折扣榜。

### 6.2 左侧导航

按系列汇总，点进去看该系列的明细。

### 6.3 系列详情

「本体 / 版本」「捆绑包」「DLC」分组；点「N 项 ⌄」展开捆绑包内含项目与分摊价。
每一行右侧是买入价与现价对比，点「价格历史」看曲线。

## 7. 备份与恢复

### 备份

程序右上角设置里能看到数据目录。直接复制这个文件夹：

```
%APPDATA%\PLAYBILL\          ← Windows（资源管理器地址栏粘贴即可打开）
  data.json                  ← 全部数据（含凭证，注意保管）
  price-history.json         ← 价格快照

~/.config/PLAYBILL/          ← macOS / Linux
```

也可以用「导出 JSON / CSV」。

### 恢复

停止程序 → 把备份的 `data.json` 覆盖回同一目录 → 重启。

### 清除凭证

右上角头像 → 「登出并清除凭证」。

## 8. 排错表

| 现象 | 原因 | 解决 |
|---|---|---|
| `EADDRINUSE` | 8787 端口被占用 | 换端口：`set PORT=8888 && npm start` |
| 登录后没数据 | 还没同步 | 点「同步交易」 |
| 抓取Cookie 报 `ECONNREFUSED 127.0.0.1:9222` | 浏览器没用调试模式启动 | 双击「启动浏览器.bat」后再抓 |
| 交易接口 `Access denied` | 会话被登出 / 调用过频 | 等 5 分钟再点；仍不行就重做第 3 节 |
| 交易同步卡住 | 正在查现价 | 看提示条「已用 N 秒」，首次 2–4 分钟属正常 |
| 当前价值显示「—」 | 现价覆盖不足 80% | 再点一次「更新商店现价与封面」 |
| 封面空白 | 网络到索尼 CDN 不稳 | 重跑「更新商店现价与封面」 |
| 页面是旧样式 | Service Worker 缓存 | `Ctrl + F5` |
| 双击 `启动程序.bat` 一闪而过 | 解压不完整（缺 `runtime`） | 重新解压，别用「Code → Download ZIP」 |

## 9. 在手机上装成 App

iPhone / Android 都可以把 PLAYBILL 装到主屏幕，像 App 一样全屏使用。
需要 HTTPS，所以要先给这台电脑配一张本机证书。

### 9.1 生成证书

双击 **`手机访问(HTTPS).bat`**。

它会生成一张只对这台电脑有效的自签证书（不联网），并存到：

```
%APPDATA%\PLAYBILL\tls\playbill.cer     ← 手机装这个
%APPDATA%\PLAYBILL\tls\playbill.pfx     ← 程序自用，别外传
```

### 9.2 以 HTTPS 重启

关掉正在运行的程序窗口，重新双击 **`启动程序.bat`**。

这次窗口里会显示：

```
PLAYBILL · 本地服务已启动（HTTPS）
手机访问（同一 Wi-Fi）： https://10.0.0.8:8787
```

### 9.3 手机安装证书

把 `playbill.cer` 传到手机（AirDrop / 微信「文件传输助手」/ 邮件附件都行），然后：

- **iPhone**：设置 → 已下载描述文件 → 安装 → 输入锁屏密码
  再进 设置 → 通用 → 关于本机 → **证书信任设置** → 打开对 `PLAYBILL` 的完全信任
- **Android**：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书

### 9.4 添加到主屏幕

Safari / Chrome 打开窗口里显示的 `https://` 地址，然后：

- iPhone：分享 → **添加到主屏幕**
- Android：菜单 → **安装应用 / 添加到主屏幕**

装好后是独立图标、全屏运行，断网也能打开外壳。

### 9.5 常见问题

- **打不开 / 提示证书不受信任**：9.3 没做完，或忘了打开「完全信任」。
- **换了 Wi-Fi 后打不开**：电脑的局域网地址变了，重新双击 `手机访问(HTTPS).bat`（会自动发现并重签），再重开程序。
- **电脑和手机不在同一网络**：手机连电脑开的移动热点即可（程序窗口里的地址会包含热点网段）。
- **不想装证书**：直接用 `http://` 地址也能看，只是 iPhone 不允许把 http 页面加到主屏幕。

## 10. 从源码运行（开发者）

需要 Node.js 20+：

```bash
git clone https://github.com/Ethanzzzz/playbill.git
cd playbill
npm start
```

Windows 也可以右键 `start.ps1` → 使用 PowerShell 运行。
