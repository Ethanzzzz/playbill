# 使用指南

面向第一次使用的人，从打开程序到看懂界面，一步步来。

> 所有数据只留在你自己电脑上。

---

## 0. 最简单的方式：下载即用

**不用装 Node.js，不用打开命令行，不用敲任何命令。**

### 三步

1. 打开 [Releases](../../releases) 页面，下载 `PSN收藏档案-绿色版-v0.1.0.zip`（约 33 MB）
2. 右键压缩包 → **全部解压**，得到一个 `PSN收藏档案` 文件夹（放到桌面就行）
3. 双击文件夹里的 **`启动程序.bat`**

等 3 秒，浏览器会自动打开 `http://localhost:8787`。

### 放到桌面上当程序用

1. 把 `PSN收藏档案` 文件夹拖到桌面
2. 右键 `启动程序.bat` → **发送到** → **桌面快捷方式**
3. 以后双击桌面图标即可

> ⚠️ 快捷方式只认原路径。**先把文件夹放到最终位置，再建快捷方式**，否则移动后会失效。

### 怎么关掉

关掉那个黑色窗口就行。

### 常见提示

| 提示 | 意思 | 怎么办 |
|---|---|---|
| `Stopped. Press any key to close.` | 程序已停止 | 按任意键关窗口 |
| 浏览器显示「无法访问」 | 服务还没起来 | 等 3 秒刷新 |
| 一闪而过 | `runtime` 文件夹不完整 | 重新解压一次 |
| 端口被占用 | 程序已开着一个 | 直接开 <http://localhost:8787> |

## 1. 准备工作

### 安装 Node.js

打开 <https://nodejs.org/>，下载 **LTS 版本**（20 或更高），一路下一步。

验证：

```bash
node -v
# v22.x.x  ← 有版本号就说明装好了
```

### 浏览器

推荐 **Edge** 或 **Chrome**。后面的 Cookie 捕获需要它们。

---

## 2. 启动程序

把项目文件夹放到任意位置，然后：

```bash
cd psn-archive
npm start
```

看到这样的输出就成功了：

```
PSN 收藏档案 已启动
  http://localhost:8787
  数据文件： .../server/data.json
  价格历史： .../server/price-history.json
```

浏览器打开 <http://localhost:8787>。

> **Windows 用户**：也可以直接右键 `start.ps1` → 使用 PowerShell 运行。

---

## 3. 登录账号

### 3.1 获取 npsso

1. 用浏览器登录 <https://www.playstation.com/>
2. **在同一个浏览器**打开：
   <https://ca.account.sony.com/api/v1/ssocookie>
3. 页面会显示一段 JSON，类似：

```json
{"npsso":"Xk9pQ2mR7vL4tN8wZ1cB6hJ3fD5gS0aE2yU4iO7pA9sD1fG3hJ5kL7zX9cV1bN3m"}
```

4. 复制那串 **64 位字符**（不带引号）

### 3.2 粘贴登录

回到应用 → 右上角 **头像图标** → 粘贴 npsso → 点「登录」。

成功后会提示「登录成功」，左侧开始出现你的数据。

> ⚠️ `npsso` 等同于你的账号密码。**不要截图发群、不要粘贴到任何网站。**

---

## 4. 同步游戏库

点右上角 **「同步游戏」**。

这会拉取：

- 你拥有的全部游戏名称与封面
- 每个游戏的平台（PS4 / PS5）
- 当前商店价格（可选，会慢一些）

首次同步约 1–3 分钟，取决于游戏数量。

---

## 5. 同步交易记录

**这是最关键的一步**，也是唯一需要折腾的地方。

### 为什么要额外一步

交易记录接口要求**网页会话 Cookie**（`npsso` + `pdccws_p`）。
`pdccws_p` 只能由浏览器登录商店时产生，无法用 npsso 直接换。

### 5.1 关闭所有浏览器窗口

必须完全退出（任务栏右键 → 退出），否则调试端口起不来。

### 5.2 用调试模式启动 Edge

> **绿色版用户**：直接双击文件夹里的 **`启动浏览器.bat`**，它会自动用调试模式打开 Edge 并进入商店首页。然后跳到 5.3。

源码运行的用户手动执行：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222
```

> Chrome 用户把路径换成 `C:\Program Files\Google\Chrome\Application\chrome.exe` 即可。

### 5.3 在这个浏览器里登录商店

打开 <https://store.playstation.com/>，确认右上角已显示你的头像（已登录状态）。

### 5.4 运行捕获脚本

**不要关掉刚才的浏览器**，回到程序文件夹：

- **绿色版**：双击 **`抓取Cookie.bat`**
- **源码版**：新开终端执行 `node tools/capture-cookies.mjs`

看到 `✅ Cookie 已保存` 就成功了。

### 5.5 同步交易

回到应用，点 **「同步交易」**。

首次会拉取全部历史订单（可能几百笔），耗时 1–2 分钟。

> Cookie 有效期约 **30 天**。之后如果提示"权限不足"，重跑 5.1–5.4 即可。

## 6. 看懂界面

### 6.1 总览

| 指标 | 含义 |
|---|---|
| **累计投入** | 你实际花出去的钱（含折扣） |
| **当前价值** | 按商店现价重算，你的收藏值多少 |
| **累计省下 / 多花** | 现价 − 买入价。正数=省了，负数=买贵了 |
| **免费领取** | 数量（0 元入库） |

下面是四张图：月度消费、消费构成、系列排行、当前折扣榜。

### 6.2 左侧系列导航

按系列汇总，例如：

```
生化危机 Resident Evil   HK$422.65
绝地潜兵 Helldivers      HK$317.00
```

点进去是**系列档案**。

### 6.3 系列档案（树形结构）

一个游戏只占一行。点行末的 **「N 项 ⌄」** 标签展开：

```
火影忍者 疾风传 终极风暴4      HK$29.80   [7 项 ⌄]
  └─ 可操纵角色组合包「音之忍者四人组」   捆绑包
     追加故事组合包「我爱罗传」          捆绑包
     NARUTO...STORM 4 Season Pass      DLC     HK$79.00
     ...
```

**没有胶囊标签的行 = 不可展开。**

### 6.4 来源徽章

| 徽章 | 含义 |
|---|---|
| （无徽章，有金额） | 你真金白银买的 |
| `会员领取` | PS Plus 会员领取，没花钱 |
| `免费领取` | 免费入库（试玩、免费 DLC） |
| `随包附赠` | 买了大包后自动到账的 |
| `其他来源` | 索尼标记为 other |

### 6.5 价格历史

点任意商品行的 **「价格历史」**：

```
史低 HK$217.56   当前 HK$217.56   你的买入 HK$255.20   记录点 2
```

- **红点** = 你的买入价（当日实付）
- **黑点** = 每日商店快照
- **红色虚线** = 史低

数据从你第一次运行那天开始积累，每天自动记录一次。

### 6.6 「其他」折叠区

每个系列底部有一个默认收起的区块：

```
其他（升级 / 试玩 / App / 头像 / 领取）  ⑤    展开
```

里面是 App、头像、试玩版、升级授权、免费领取等**非游戏商品**，不干扰主列表。

## 7. 备份与恢复

### 备份

点右上角 **「导出 JSON」**，得到 `psn-backup-日期.json`。

也可以直接复制这两个文件：

```
server/data.json            ← 你的全部数据（含凭证，注意保管）
server/price-history.json   ← 价格快照
```

### 恢复

停止程序 → 把备份文件覆盖回 `server/` → 重启。

### 清除凭证

右上角头像 → 「登出并清除凭证」。

## 8. 排错表

| 现象 | 原因 | 解决 |
|---|---|---|
| `EADDRINUSE` | 8787 端口被占用 | 换端口：`set PORT=8888 && npm start`（Windows） |
| 登录后没数据 | 还没同步 | 点「同步游戏」 |
| 「权限不足」 | 缺 `pdccws_p` Cookie | 重跑第 5 节 |
| 交易同步卡住 | 订单太多 | 等 2–3 分钟，或先只同步近一年 |
| 封面全部空白 | 网络无法访问索尼 CDN | 检查代理，或在设置里关掉「加载封面」 |
| 价格全是「未知」 | 未同步商店价 | 同步游戏时勾选「同时抓取商店现价」 |
| 页面是旧样式 | Service Worker 缓存 | `Ctrl + F5` 强制刷新 |
| 交易记录重复 | 多次同步叠加 | 在设置里点「重置交易数据」后重新同步 |

---

## 附：用 CSV 导入（备用方案）

如果 Cookie 方式实在走不通，可以用官方 CSV：

1. 登录 <https://account.sony.com/> → 交易记录
2. 导出 CSV
3. 应用内点「导入 CSV」→ 选择文件

CSV 只包含订单层面信息，**不含商品明细**，分析精度会低一些。
